# Imam Bukhari Trust website

Official website prototype of Imam Bukhari Trust (IBT), Uttara, Dhaka: Bangla, English and Arabic.

- Live: https://shak-nayem-uddin.github.io/ibt-website/
- Maintenance and deployment guide: [docs/MAINTENANCE.md](docs/MAINTENANCE.md)
- Content admin: `#admin` on the live site (GitHub token sign-in)

Static site on GitHub Pages; no build server. Default content lives in `data/content.json`; edits from the admin panel are stored in `data/cms.json`.
