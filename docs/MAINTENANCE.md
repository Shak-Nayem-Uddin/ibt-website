# IBT website: deployment and maintenance

Live site: https://shak-nayem-uddin.github.io/ibt-website/ (GitHub Pages, branch `main`, repository root).
Backup of the site before the November 2026 upgrade: branch `backup/pre-master-upgrade`.

## How the site is built

| Part | Where | Notes |
| --- | --- | --- |
| Page shell | `index.html` | Loads CSS/JS with `?v=` cache-busting. Bump the version after changing assets. |
| Styles / design tokens | `assets/app.css` | Tokens at the top: colours (light/dark), radius, fonts. |
| Pages and logic | `assets/app.js`, `pages.js`, `extras.js`, `ask.js`, `v8.js` | Plain JavaScript, no build step. Hash routes (`#about`). |
| 3D campus | `assets/scene3d.js` + `assets/vendor/three.min.js` | Master-plan layout from `data/content.json` → `masterplan`. |
| Content (default) | `data/content.json` | Generated by `python build_content.py` from `content_v3.py` … `content_v8.py`. |
| Content (admin edits) | `data/cms.json` | Written by the admin panel; overrides sections of content.json. |
| Search-engine pages | `<route>/index.html`, `sitemap.xml`, `robots.txt` | Generated by `python tools/prerender.py`. |
| Fonts | `fonts/` | Kalpurush (Bangla, OFL), Plus Jakarta Sans, Noto Naskh Arabic, Amiri Quran; all self-hosted. |
| Images | `img/` | WebP copies are used automatically when smaller (build step). Originals stay. |

## Everyday editing (no code)

1. Open the site and go to `#admin` (menu → "আরও"/footer, or add `#admin` to the address).
2. Sign in with a GitHub fine-grained token: repository `ibt-website` only, permission **Contents: Read and write**.
3. Pick a section, edit Bangla/English/Arabic text, upload photos, then **Save draft → Preview → Publish**.
4. Changes appear on the live site 1–2 minutes after publishing. Every publish is a commit (full history in GitHub).

Keep the token private. Revoke it on GitHub if a device is lost.

## Automations (GitHub Actions)

| Workflow | Schedule | What it does |
| --- | --- | --- |
| `youtube.yml` | every 3 hours | Updates `data/videos.json` from the IBT and Kulliyatul Quran YouTube channels. |
| `live.yml` | every 10 minutes | Detects live/upcoming YouTube streams → `data/live.json` (red dot + Live page). |
| `qa.yml` | daily ~02:40 Dhaka | Refreshes the Islamic Q&A index (`data/qa.json`): titles and links only. |

Facebook/Zoom live links are set by hand in the admin panel → "লাইভ সম্প্রচার".

## Developer tasks

- Rebuild default content: `python build_content.py`
- Refresh static SEO pages after important content changes: `pip install playwright && playwright install chromium && python tools/prerender.py`
- Local preview: `python -m http.server` in the repo root, open `http://localhost:8000/`.
- Before pushing: open the main pages in light/dark and on a phone width; check the browser console has no errors.

## Rules that protect credibility

- Never publish a statistic, financial figure, legal registration detail, committee member or audit claim that is not in an approved record. Use the "pending approval" states instead.
- Payment numbers change only with written authorisation from IBT management.
- No secrets in this repository: it is public. Tokens live only in the editor's browser.
- Prayer times default to Uttara, Dhaka (23.8759 N, 90.3795 E, Asia/Dhaka, Karachi method, standard Asr) and are calculated in the browser with adhan.js; they are never hard-coded.
